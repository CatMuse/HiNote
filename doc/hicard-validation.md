# HiCard 验证记录

## 本轮行为

- 全部卡片、未分组和已暂停是内置视图，不写入用户自定义分组。
- 暂停不删除复习记录，不改变到期时间；恢复后继续受每日限额约束。
- 评分和撤销先写入隔离副本，写盘成功后才更新其他视图可见的状态。
- 普通保存与评分使用同一写入队列，在执行时获取最新已提交状态。
- 写盘期间的答案修改由后续保存保留，撤销仅恢复排程与统计。
- 自动入队同时刷新顶部、分组、待学计数；答案编辑期间延后刷新。
- 视图关闭、切换分组或跨天会使旧的异步界面更新失效。
- 窄屏按容器宽度切换布局，保留卡片 DOM；提供返回分组按钮。

## 自动验证

运行 `npm run test:flashcards`，覆盖：

1. FSRS 多轮评分后状态、步数、间隔完整往返。
2. 学习参数重启恢复、旧记录兼容。
3. 修改动态筛选后新增匹配卡片，旧匹配卡片仍保留。
4. 每日限额、分组限额、短期学习卡、当地午夜额度恢复。
5. 写盘失败期间其他视图仍看到旧评分；后续排队保存不会写入失败评分。
6. 写盘期间修改答案，评分提交和撤销均保留该修改。
7. 撤销恢复复习历史、额度和统计。
8. 分组状态使用 ID；当前卡片消失后替代卡片从正面显示。
9. 离线授权宽限、超期和明确拒绝。
10. 答案编辑期间推迟自动刷新；空队列到期后显示学习卡。
11. 关闭组件后评分完成，不重绘已关闭视图。
12. 暂停后不参与复习，禁止评分，重启仍暂停；恢复保留到期时间。
13. 未分组卡片可找到，总数不重复统计，内置分组不写入用户分组。

另外运行 `npm run build`、`npm run test:storage`、`npm run test:views`、`npm run test:review`。

## 独立 HiCard 视图

- 新增 `hicard-view` 工作区视图和稳定命令 `hi-note:open-hicard`（打开 HiCard），另提供书本爱心功能区入口。
- HiCard 默认打开独立标签页；重复或并发执行打开命令复用已有视图，不移动或关闭高亮页。
- 高亮文件列表移除内嵌 HiCard 模式；保留制卡、源关联和闪卡标记。现有卡片、分组、学习历史和授权沿用原存储，无需迁移。
- 视图恢复时等待服务初始化；关闭会卸载组件。晚到的初始化、授权响应不会重建已关闭界面。加载失败支持重试。
- 新增 `npm run test:hicard-view`，覆盖独立打开、并发打开、关闭期间初始化/授权、组件清理和失败重试。
- 本次构建及 `test:hicard-view`、`test:views`、`test:flashcards`、`test:storage`、`test:review` 均通过。尚未在实际 Obsidian 中完成独立视图的拖动、弹出窗口和重启恢复验收。
