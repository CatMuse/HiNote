# HiNote 0.6.1

- 新增「设置 → HiNote → 常规 → 划词工具栏」开关，默认开启。
- 关闭后，选中文字或点击高亮不再弹出 HiNote 浮窗；重新开启无需重启插件。
- 关闭划词工具栏不影响高亮卡片色条的手动调色。
- 最低支持版本保持为 Obsidian **1.14.0**。

## English

- Added a **Selection toolbar** toggle in HiNote's general settings, enabled by default.
- Turn it off to stop the floating toolbar from appearing when selecting text or clicking a highlight. Changes take effect without restarting the plugin.
- The highlight-card color palette remains available when the selection toolbar is disabled.
- Requires Obsidian **1.14.0** or later.
