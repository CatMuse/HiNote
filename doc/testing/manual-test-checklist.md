# HiNote 整体验收测试清单

基线：本地 master `7fa470b`（2026-10-17），版本号为 `0.5.8`，包含当前开发功能；不等同于 GitHub 已发布的旧 0.5.8 安装包。本清单依据当前 README 与代码整理，尚未逐项执行。

## 使用方法

- 先复制一份完整测试库，包含 `.obsidian` 和 `.hinote`；破坏性、数据损坏、写入失败测试仅在副本进行。
- P0：核心链路与数据安全，发布前必须通过。P1：完整体验与兼容性，也应完成；缺少设备或服务时标为“未测”，不能视为通过。
- 勾选表示通过；失败/阻塞/未测另记到文末记录表。建议先完成所有 P0，再跑 P1。
- 同一关键操作至少在实时预览和阅读模式各走一次；源码模式重点核对实际 Markdown，而非要求所有装饰一致。
- AI 用专用测试密钥和非敏感样本；真实请求可能计费。没有相应服务或 Pro 授权时，标明覆盖缺口。

## 测试准备

记录：Obsidian 版本、系统/设备、主题、语言、插件提交、是否 Pro、数据规模。

建议准备：笔记 A（各格式高亮）、B（重复文本）、C（空白/无高亮）、一个排除文件夹、一个实际命名为 `demo.xcd.md` 的笔记、三条不同内容的评论，以及新卡/学习中/到期/未来到期/暂停卡。另备少量正式 0.5.8 创建的历史数据。

可复制以下内容到测试笔记 A；把红橙黄绿蓝紫圆点再替换为对应方块，重复颜色测试。

```markdown
# HiNote 测试 A

普通中文 English 123 与 Emoji 🐙。

==默认高亮==
==🔴红色高亮==
==🟠橙色高亮==
==🟡黄色高亮==
==🟢绿色高亮==
==🔵蓝色高亮==
==🟣紫色高亮==

<mark>mark 高亮</mark>
<span style="background-color: #ffeb3b">span 高亮</span>

上下文甲：==重复高亮==。为它添加评论“甲评论”。
上下文乙：==重复高亮==。为它添加评论“乙评论”。

==带有 {{挖空答案}} 的闪卡来源==

[[HiNote 测试 B]] #hinote-test
```
